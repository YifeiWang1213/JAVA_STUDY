## 题目描述

给定字符串 `s`，找出其中不含重复字符的**最长子串**的长度。

```
输入：s = "abcabcbb"
输出：3   // "abc"
```

## 思路

维护一个窗口 `[left, right]`，保证窗口内没有重复字符：

1. `right` 向右扩张，把字符加入窗口
2. 如果新字符在窗口中已存在，`left` 直接跳到该字符上次出现位置的下一位
3. 每一步更新答案 `right - left + 1`

## 代码

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[128];   // 记录字符上次出现位置 + 1
        int ans = 0;
        for (int left = 0, right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            left = Math.max(left, last[c]);
            ans = Math.max(ans, right - left + 1);
            last[c] = right + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(|Σ|)，字符集大小 128

## 反思 / 易错点

- `left` 只能右移，所以要取 `Math.max`，否则遇到 "abba" 会出错
