## 推荐：直接在网页上写

1. 打开博客，点页面最底部的「**写作后台**」
2. 第一次需要粘贴 GitHub Token 登录（[点这里生成](https://github.com/settings/tokens/new?scopes=repo&description=博客写作)，勾选 `repo`），之后这个浏览器会记住
3. 登录后右上角会出现「✍️ 写文章」，每篇文章下也会有「编辑 / 删除」按钮
4. 写完点「发布」或按 `⌘/Ctrl + S`，约 1 分钟后所有访客都能看到

编辑器小功能：

- 左边写 Markdown，右边实时预览，可切换「编辑 / 分屏 / 预览」
- 截图后直接 `⌘ + V` 粘贴，或把图片拖进编辑框，会自动上传
- 「📄 模板」一键插入笔记 / 题解模板
- 写到一半关掉页面也没关系，草稿会自动保存在本机，下次打开自动恢复

> 在电脑上用 `启动博客.command` 打开的本地版（localhost）不需要登录，文章直接保存到 `posts/` 文件夹。

## 零、用双击脚本

在 Finder 里打开 `blog` 文件夹，双击对应文件即可：

| 文件 | 作用 |
| --- | --- |
| `启动博客.command` | 启动博客并打开浏览器 |
| `写新文章.command` | 弹窗选择「笔记 / 题解」、输入标题，自动生成模板并用 Cursor 打开 |
| `发布到网上.command` | 一键发布到 GitHub Pages（第一次需要填仓库地址） |
| `停止博客.command` | 关闭本地博客 |

> 第一次双击如果提示“无法打开”，右键 → 打开 → 再点一次「打开」即可。

## 一、新建文章（命令行方式）

在 `blog` 目录下打开终端：

```bash
# 新建学习笔记
npm run new -- note "HashMap 底层原理"

# 新建刷题题解：题目名 + 难度 + 原题链接
npm run new -- algo "两数之和" 简单 https://leetcode.cn/problems/two-sum/
```

命令会在 `posts/` 下生成一个带模板的 `.md` 文件，直接编辑即可。也可以手动在 `posts/` 里新建 `.md` 文件。

## 二、Front Matter 字段说明

每篇文章开头 `---` 之间的部分：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| title | 标题 | HashMap 底层原理 |
| date | 日期 | 2026-11-27 |
| category | 分类：`笔记` 或 `刷题` | 刷题 |
| tags | 标签，数组写法 | [集合, 面试] |
| difficulty | 难度（刷题用）：简单 / 中等 / 困难 | 中等 |
| source | 原题链接（刷题用） | https://leetcode.cn/... |
| summary | 摘要，不写则自动截取正文 | |
| pinned | 是否置顶 | true |
| draft | 草稿，为 true 时不显示 | true |

## 三、本地预览

```bash
npm run dev
```

浏览器打开 <http://localhost:4000>。修改 `posts/` 里的文章后**刷新页面**即可看到效果（服务器会自动重建索引）。

> 注意：不要直接双击 `index.html` 打开，浏览器会禁止读取本地文件。

## 四、个人信息

修改 `assets/config.js`：站点标题、昵称、简介、GitHub 链接，以及侧栏的**学习路线**（`done: true` 表示已完成）。

## 五、部署到 GitHub Pages

1. 在 GitHub 新建一个**公开**仓库（例如 `java-notes`），不要勾选 README
2. 双击 `发布到网上.command`，粘贴仓库地址，如 `https://github.com/用户名/java-notes.git`
3. 推送时如果要密码：用户名填 GitHub 用户名，密码填 **Personal Access Token**（GitHub → Settings → Developer settings → Personal access tokens，勾选 `repo` 权限）
4. 第一次发布后，在仓库 Settings → Pages → 分支选 `main`、目录选 `/ (root)` → Save
5. 几分钟后即可通过 `https://用户名.github.io/java-notes/` 访问

以后每次写完文章，再双击一次 `发布到网上.command` 就会自动更新。

## 六、Markdown 小技巧

- 行内代码：`String.valueOf()`
- 引用块用 `>` 记录重点
- 任务清单：

- [ ] 学完 Java 基础
- [ ] 刷完 LeetCode Hot 100

快捷键 `Ctrl/⌘ + K` 可以打开全文搜索。
